# Experimental Method

## Purpose

This document defines a practical workflow for observing and documenting recurring tendencies in generative AI outputs.

The goal is to distinguish personal impressions from patterns that can be observed repeatedly.

## Workflow Overview

**Question → Prompt → Generation → Observation → Repetition → Comparison → Conclusion**

### 1. Define the Question

Start with one specific question.

Examples:

- Does a generator repeatedly favor a particular visual aesthetic?
- Does it preserve small character details across multiple generations?
- Does it interpret the same instruction differently from other generators?
- Does a music generator repeatedly produce similar arrangements under similar instructions?

Each experiment should investigate one primary behavior whenever practical.

### 2. Record the Prompt

Save the exact prompt used for each generation.

Record any reference images, additional instructions, negative prompts, or editing instructions that may influence the result.

Do not silently rewrite the original prompt after observing the output.

### 3. Record the Generation Conditions

Document the information available about the generation:

- Tool or model name
- Model version, if known
- Date of the experiment
- Generation settings, if available
- Reference inputs
- Number of attempts
- Any relevant editing or post-processing

If a detail is unknown, mark it as unknown rather than guessing.

### 4. Observe the Output

Describe what actually appeared in the result.

Separate direct observations from interpretations.

For example:

**Observation:** Three out of four generated images used similar centered compositions.

**Interpretation:** The generator may favor centered compositions under these instructions.

The observation describes the outputs. The interpretation proposes a possible explanation.

### 5. Repeat the Experiment

A single result is not enough to establish a recurring tendency.

Generate multiple outputs under comparable conditions. Record exceptions as well as similarities.

When practical, change one factor at a time to investigate its influence.

### 6. Compare Results

Compare outputs using clearly defined criteria relevant to the experiment.

Possible criteria include:

- Stylistic consistency
- Prompt adherence
- Character-detail preservation
- Composition
- Variety across outputs
- Response to corrective instructions

Not every criterion applies to every experiment.

### 7. Report the Findings

Summarize:

- What was observed
- How often the pattern appeared
- What changed across attempts
- Alternative explanations
- What remains uncertain

Use cautious language when the evidence is limited.

## Evidence Categories

**Observed:** Directly visible or audible in recorded outputs.

**Repeated:** Observed across multiple attempts under documented conditions.

**Hypothesis:** A possible explanation that needs further testing.

**Unresolved:** Evidence is insufficient, inconsistent, or incomplete.

## Important Limitations

Generative outputs may vary because of randomness, model updates, settings, prompt interpretation, reference inputs, and other factors.

A pattern observed in one experiment does not automatically generalize to every prompt, task, model version, or user.

## Guiding Principle

Document what happened before explaining why it happened.
